# NGB missions

Each mission is a stage script m_NN<area>.sty inside the area shared archive (*_cmn.afs); listed by tools/ngb_missions.py. Enemy lists = op 0x5b type arguments: clean for small missions; missions built on a whole story stage also list that stage types, so treat those as upper bounds. g_*.grp = room geometry groups (not load lists); s_*_l/_l2/_l4.sty = difficulty variants; item*_N.sty = item missions (hell_cmn); debug.afs has test scripts (s_v<boss>.sty boss viewers, s_chrput.sty, s_m_edit.sty).
